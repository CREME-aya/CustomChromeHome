Nexus Dash Privacy Policy

Effective date: June 16, 2026

This is an English translation. If it differs from the Japanese version, the Japanese version prevails.

Nexus Dash is a personal dashboard extension that shows and controls a clock, weather, to-dos, Google Calendar events, RSS feeds, AI chat, and Spotify information on Chrome's new tab page.

This extension uses the information that users set or enter only to provide its features. Collected information is never used for advertising or sold to third parties.

Information collected or stored

Depending on usage, this extension stores the following information in the browser.

  • To-dos, their completion state, and event IDs from Google Calendar
  • Google Calendar iCal URL and import range
  • RSS / Atom feed URLs, favorite articles, and search / display settings
  • Background image URL, or background image data saved in the browser
  • Quick link titles and URLs
  • API keys for OpenAI, Anthropic, and Google Gemini
  • Spotify access token, refresh token, and token expiry time
  • The place name and location settings the user specified for the weather display
  • Widget show / hide settings

Information sent to external services

To provide its features, this extension may send information to the following external services.

  • Open-Meteo API: for weather, precipitation, and location search
  • Google Calendar iCal URL: to fetch calendar events
  • OpenAI API, Anthropic API, Google Gemini API: to send the AI chat content entered by the user
  • Spotify API: for authentication, getting the currently playing information, and playback control
  • RSS / Atom feed URLs: to fetch the article feeds set by the user

Information is sent only when the user uses the corresponding feature. User data is never sent to any server operated by the developer of this extension.

Storage location and retention period

Settings and entered content are mainly stored in the browser's localStorage. Stored information is kept until the user deletes the browser's site data, removes the extension, or changes or deletes the settings in the app.

Third-party sharing and advertising

This extension does not use collected or stored information for advertising. It also does not sell or share user data with third parties. However, when the user uses external API features, the information needed to provide the feature is sent to each external service.

Remote code

This extension does not load and run executable code, such as JavaScript or WebAssembly, from external servers. The extension's executable code consists only of the files included in the package.

User control

Users can delete or update stored information by deleting the browser's site data, removing the extension, or changing each setting in the app.

Changes

This policy may be updated as features are added or specifications change. If there is an important change, the content of this published page will be updated.

Contact

For inquiries about this extension, use the developer contact shown on the Chrome Web Store listing page, or open an Issue in the source repository.
